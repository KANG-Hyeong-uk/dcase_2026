# DEFT 기반 CLAP Similarity Feature 실험 계획 (수정본)

## 0. 실험 목적

BSD10k에는 전문가가 부여한 confidence label이 존재한다.

```text
confidence = 1,2,3,4,5
```

본 실험의 목적은 CLAP 기반 similarity feature가 confidence를 설명할 수 있는지 확인하고,

최종적으로 BSD35k noisy label filtering에 사용할 수 있는 confidence feature를 찾는 것이다.

핵심 가설:

```text
audio와 text가 잘 맞을수록 confidence가 높다.

audio와 class 의미가 잘 맞을수록 confidence가 높다.

현재 class가 다른 class보다 명확하게 우세할수록 confidence가 높다.
```

---

# 1. 생성할 Similarity Features

## 1.1 audio_text_sim

```python
audio_text_sim =
cosine(audio_emb, text_emb)
```

text_emb:

```text
title
+
tags
+
description
```

의미:

```text
오디오와 사용자가 작성한 설명이 얼마나 일치하는가
```

---

## 1.2 audio_class_sim

class label을 자연어 문장으로 변환한다.

예:

```text
sp-s
→
"A speech sound containing spoken human voice"

ss-u
→
"A musical instrument sound"

fx-o
→
"A sound effect recording"
```

CLAP text embedding 생성:

```python
class_text_emb =
CLAP.encode_text(class_prompt)
```

유사도 계산:

```python
audio_class_sim =
cosine(audio_emb, class_text_emb)
```

의미:

```text
오디오와 현재 class 의미가 얼마나 일치하는가
```

---

## 1.3 label_margin

모든 class text embedding과 similarity 계산.

```python
assigned_class_sim =
cosine(audio_emb, assigned_class_text_emb)

best_other_sim =
max(other_class_similarity)

label_margin =
assigned_class_sim
-
best_other_sim
```

의미:

```text
현재 class가 다른 class보다 얼마나 더 그럴듯한가
```
